# ReChigros

ReChigros 是一个用 C++20、SDL3 与 OpenGL 编写的《Phigros》模拟器，支持Windows、Android 与 iOS

ReChigros is a Phigros simulator written in C++20 with SDL3 and OpenGL, with desktop, Android and iOS builds.

## 构建 / Build

依赖 / Requirements:

- CMake 3.20 或更新 / CMake 3.20 or newer
- 支持 C++20 的编译器 / A C++20 compiler (MSVC 2022, Clang or GCC)
- SDL3 由 CMake 自动下载并构建 / SDL3 is downloaded and built by CMake
- Android：Android SDK 36、NDK、JDK 17
- iOS：Xcode 与 CMake 的 iOS 工具链 / Xcode with the CMake iOS toolchain

桌面端 / Desktop:

```sh
cmake -S . -B build/desktop -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build/desktop
ctest --test-dir build/desktop --output-on-failure
```

仓库也提供统一的构建脚本 / The repository also ships a unified build script:

```sh
# Windows
build.bat desktop Release
# Linux / macOS（需要 PowerShell）
./build.sh -Target desktop -Configuration Release
```

Android:

```sh
scripts/build.ps1 -Target android -Configuration Release
```

产物位于 `platform/android/app/build/outputs/apk/release/`

The package is written to `platform/android/app/build/outputs/apk/release/`.

iOS（在 macOS 上 / on macOS）:

```sh
scripts/build.ps1 -Target ios -Configuration Release
```

也可以使用 `.github/workflows/ios-build.yml` 在 GitHub Actions 的 macOS 运行器上构建

The workflow in `.github/workflows/ios-build.yml` builds the same project on a macOS runner.

## 目录结构 / Layout

| 路径 / Path | 内容 / Contents |
| --- | --- |
| `src/core/` | 判定、时钟、谱面运行时 / Judging, clocks and chart runtime |
| `src/chart/` | 官方、RPE、PEC 谱面解析 / Chart parsers |
| `src/render/` | 场景、特效、着色器与皮肤渲染 / Scene, effects, shaders and skin rendering |
| `src/audio/` | 音频引擎与解码 / Audio engine and decoding |
| `src/app/` | 界面、曲库、回放与录像 / Interface, library, replays and recording |
| `src/platform/` | 文件、资源与平台对话框 / Files, assets and platform dialogs |
| `platform/android/` | Android 工程 / Android project |
| `platform/ios/` | iOS 打包资源与启动屏 / iOS packaging resources |
| `assets/` | 运行所需的内置资源 / Bundled runtime assets |
| `tests/` | 单元测试 / Unit tests |
